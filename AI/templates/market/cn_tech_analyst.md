按下列 JSON 结构输出（只替换尖括号内容，键名与枚举原样保留；数据不足的级别填
“信息不足”，并在 evidence 中写明缺失项）：
```json
{
  "short_term": {"level": "<短线级别>", "evidence": "<证据：引用特征块具体数值>", "confirm": "<确认条件>", "invalidate": "<失效条件>", "confidence": "<high/medium/low>"},
  "wave": {"level": "<波段级别>", "evidence": "<证据>", "confirm": "<确认条件>", "invalidate": "<失效条件>", "confidence": "<high/medium/low>"},
  "long_term": {"level": "<长线级别>", "evidence": "<证据>", "confirm": "<确认条件>", "invalidate": "<失效条件>", "confidence": "<high/medium/low>"},
  "style": "<风格标签>",
  "sentiment_cycle": "<情绪周期位置>",
  "as_of_date": "<YYYY-MM-DD>"
}
```
- short_term.level 只能是：适合 / 谨慎 / 回避 / 信息不足
- wave.level 只能是：进攻 / 平衡 / 防御 / 信息不足
- long_term.level 只能是：配置窗口 / 等待窗口 / 信息不足
- style 只能是：大盘成长 / 大盘价值 / 小盘成长 / 小盘价值 / 均衡 / 信息不足
- sentiment_cycle 只能是：冰点 / 修复 / 高潮 / 退潮 / 信息不足
- 每级必须给出：级别 → 证据 → 确认条件 → 失效条件 → 置信度；正文详述须与 JSON 块一致
