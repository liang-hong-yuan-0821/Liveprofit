## 架构

市场层是一个**独立编译的 LangGraph 子图**（`AI/marketAgents/market_layer_graph.py`），与父图共享 `AgentState`。串行拓扑（证据驱动改造后）：

```
START → 国际事件提取 → 国际影响 → 中国新闻 → 中国技术 → Risk Gate（纯代码）→ END
        （预取事件研究）  （全球风险） （资金日历） （技术环境）   （derive_risk_gate）
```

设计原则：**数据先聚合、规则先计算，LLM 仅负责解释与条件化判断**。特征层（`AI/dataflows/market_features.py`）在 LLM 调用前构建可复现、带时点的特征；`risk_gate` 只消费结构化状态，由独立纯代码节点按有序规则表短路判定，不依赖任何 LLM 输出。

## 三级事件路由与预取（2026-09-11）

- 事件库 `events` 表带 `event_scope`（market/sector/stock）+ `affected_scope_refs`（行业申万代码 / 概念东财 dc 代码 / 股票统一后缀），由 **AI 预标注建议 + 审核人确认**写入（平台审核链路，服务端校验格式/存在性/组合，失败 `REVIEW_ROW_FAILED` 行级重提）。
- 市场/板块/个股信息 Agent 在 LLM 调用前由各自预取器（`international_event_prefetch.py` / `sector_event_prefetch.py` / `stock_event_prefetch.py`）**进程内直连** `review_dao` 与 `predict_impact`：固定窗口（首期 `000300.SH` + `post_event_5d`）、`as_of=event_time` 防前视、每层最多 5 条；失败降级（`no_sample` / `coverage_missing` / `api_unavailable`）不阻塞节点，历史统计不得由 LLM 补写。
- 技术 Agent（CN/板块/个股）不读取任何事件或信息研究报告；板块技术可消费板块新闻主线的结构化摘要做技术确认（板块层约定边界）。

## Layer 0 — 国际事件提取与国际影响

- 国际事件提取：事实识别、分类、历史影响解释与可比性边界；事实只来自输入、仅提取 0–5 个重大事件；输出结构化 `international_events`（事件事实 + 预取历史统计 + 置信度 + 数据质量）。
- 国际影响：事件类证据只消费 `international_events`；风险价格证据来自 `build_global_risk_features`（美债曲线/期限利差、海外股指、USDCNH/黄金；VIX/SOX/DXY/WTI 不可得，用 SPX/IXIC 已实现波动率与国内期货替代并标注）；输出 `global_risk_assessment`（`systemic_risk`/`risk_appetite`/`confidence`/证据/传导/数据质量，枚举见方案第十二章）。
- 事件研究 ToolNode 已移除（不再注册 `search_similar_events` 工具）。

## Layer 1 — 中国市场 (CN) ★

**中国新闻分析**：消费 `build_cn_event_calendar_features`（5/20/60 交易日窗口压力分级：IPO 募资额/解禁市值/交割/两融历史/事件日历），只分析可验证日历、其余显式降级；输出结构化 `market_event_calendar`（dict：三级别 level/score/drivers/key_dates/confidence + data_quality）。

**中国技术分析**：消费 `build_cn_technical_features`（7 指数 MA5/20/60/120/250、斜率、收益、量比；宽度/高标情绪；资金 1/5/20 变化；风格；估值分位；流动性），只使用预计算特征、固定枚举，按"结论→证据→确认条件→失效条件→置信度"输出结构化 `market_regime`（dict：`short_term`/`wave`/`long_term` + `style`/`sentiment_cycle`/`data_quality`）。

**Risk Gate**：独立纯代码节点（CN Tech 之后、接 END）调用 `derive_risk_gate(global_risk_assessment, market_regime, market_data_quality)` 按第十二章有序规则表短路判定（枚举 `normal/caution/block` 不变；数据质量不足最高 `caution`；fail-open 已改 fail-cautious）。

## 数据质量与时点

- `market_data_quality` 由图启动单点写入（`build_data_quality_summary`，无 reducer，节点只读）；节点级缺失内嵌于各结构化输出的 `data_quality` 子字段。
- 全部特征携带 `as_of_date`，晚于 `trade_date` 的数据丢弃并记录 `future_data_detected=True`；lookbacks/windows 均为交易日口径。

## 下游消费

市场层结构化结论（`global_risk_assessment` → `international_events` → `market_regime` → `market_event_calendar`）按优先级注入下游：结构化摘要优先（dict → 紧凑 Markdown 渲染），长文本 report 仅展示或调试；`risk_gate` 供仓位管理消费。板块/个股层各自预取本层作用域事件（`sector_events`/`stock_events`），原始事件不跨层透传。

## 每日研究对接（2026-09-23）

- 每日新闻报告由 `backend/modules/daily_research/application/news_pipeline.py` 先冻结 news cutoff，再将同一版已接受/有争议的事件上下文送入既有中国市场与板块子图；技术分析仍只使用对应交易日行情。日报快照保存 `cn_news`、`cn_tech`、板块新闻/技术/轮动结论和风险门控，详情见 `report.market_outlook.market_agents`。
- 每日图通过 AgentState 的 `daily_research_context` 注入明确的事件清单和截止时间；它不会在图内重新抓取新闻，也不启用 live tool loop，因此市场层和板块层消费的是同一冻结输入。
- 量化批次只读取截至 `event_as_of` 可见的 accepted assessment。候选事件评分只应用到明确的个股/板块目标，市场级事件进入市场展望与风险门控，不广播成每只股票的分数。
- 新闻标签独立于价格兑现：日报按完整交易日窗口记录1/5/20日原始收益、基准收益、超额收益和方向是否匹配；证据不够、窗口未成熟或无法还原历史板块成分时分别标记，不推断因果。
- 量化日报使用独立“扫描排序”合同。未提供组合绑定时只展示候选及新闻贡献，不将排序分伪装成仓位百分比或买入授权。
- 普通每日量化在策略扫描前调用 Worker 装配的共享 `RefreshService`：定时任务走 auto 准入、手动任务走 retry 准入，内部资源 `CN_STOCK_QUANT_INPUTS` 不暴露给市场页面 API。补齐复用现有行情表、market-data Worker 和 PostgreSQL advisory lock，不新增行情表。
- 量化数据就绪按冻结的活动股票目录独立检查四项：日线要求全覆盖（可信停牌可豁免），qfq、复权因子和交易状态各至少 95%。预检完成后，量化 `REPEATABLE READ` 快照会再次校验共同水位和股票目录 SHA-256；未就绪时 deadline 前重试，到期直接保存零策略 partial，不运行策略。
- `quant_news_refresh` 只复用父量化批次的行情快照和扫描结果，不触发新行情补齐，也不改变父批次候选集合。
