> **架构定位**：三层金字塔的第二层。在市场层之后、个股层之前执行。
>
> **关联文档**：[index.md](../../index.md) | [市场层](市场层.md) | [个股层](个股层.md)

>
> 全市场行业/概念板块的横向强弱对比、轮动排名，已覆盖申万一级行业（31 个）和同花顺概念板块（700+）。

## 架构

板块层是一个**独立编译的 LangGraph 子图**（`AI/sectorAgents/sector_layer_graph.py`），与父图共享 `AgentState`，写入板块层字段后保持独立（不注入个股层决策节点）。

```
顶层 Graph
├── Subgraph: 市场层（独立编译 ✅）
├── Subgraph: 板块层（独立编译）    ← 本期实现
│   ├── 板块新闻分析 (Sector News)      — 行业排名 + 资金流向 + 板块轮动 + 政策/事件催化（事件流）
│   ├── 板块技术分析 (Sector Tech)      — 全行业技术扫描 + AI专题深挖 + 风格验证
│   └── 板块轮动预测 (Sector Rotation)  — 题材轮动矩阵 + 概念逐日涨幅 + 连板梯队情绪周期
│                                        + 行业基本面 + 主线判定/轮动期追高低吸 + 明日预测
│                                        └─ charts.py 热力图 → reports/charts/*.html（logviewer 渲染）
└── 个股层 + 辩论 + 风控
```

## 板块新闻分析

**职责**：从"信息面 + 资金面"维度，扫描全市场行业板块和概念板块的状态。

- 申万一级/二级行业近 N 日涨跌幅排名 + **近 10 个交易日逐日涨跌幅矩阵**，识别领涨/领跌行业及持续性
- 行业板块主力资金净流入/流出排名，判断资金进攻方向
- 热门概念板块的涨幅、成交额变化、持续性判断（热度 TOP30 附逐日涨跌幅矩阵）
- **近期产业政策/重大行业新闻（事件研究系统事件流：PG approved + Redis pending 合并去重，近 7 日、产业政策或重要性≥4）**——逐条判断利好/利空方向与受影响板块，沉淀「政策/事件催化」章节；待审核快讯为 AI 预填分类，需自行甄别
- 板块轮动主线判断（有主线/快速轮动/无方向）及置信度

## 板块技术分析

**职责**：逐行业做技术面体检，输出全行业技术状态全景图。覆盖 A 股所有申万一级行业（汽车、医药、食品饮料、电力设备、电子、银行……）。

- **全行业技术扫描**：逐行业做均线/趋势/量价分析，输出技术状态矩阵（强势/中性/弱势）
- **行业相对强度 (alpha)**：各行业相对大盘的超额收益排名
- **板块轮动技术验证**：对新闻分析识别的"主线"做技术面确认（趋势健康度、量价配合）
- **行业技术风险扫描**：领涨行业是否出现背离/高位放量滞涨；超跌行业是否出现底部企稳信号
- **AI/科技产业链专题**：科技相关行业的上下游轮动分析（存储芯片→半导体→光模块→AI服务器→算力→AI应用）
- **全球科技映射**：美股科技→韩股科技→A股科技板块的传导有效性判断

## 板块轮动预测

**职责**：基于四块数据（Tushare 打板题材轮动矩阵 + 东财概念逐日涨幅 TOP20 + 全市场连板梯队情绪数据 + 行业基本面），识别强势主线、新晋热点和退潮板块，判断情绪周期位置，输出明日最可能上涨的题材板块预测；**主线判定为轮动期（无明确主线）时输出适合追高组/适合低吸组战术分组**。

- **逐日轮动矩阵**：拉取近 10 个交易日每天单独的题材板块 TOP 排名（含涨停家数、连板家数、连板高度）
- **上榜统计与轮动分类**：识别持续主线（连续上榜）、新晋异动（最后 1-2 天新上榜）、退潮（掉出榜单）、蓄势上升（TOP N 外排名持续爬升）
- **强度分级**：基于涨停家数分位数（P30/P70）和连板高度中位数（P50）自适应分级——强势主线/普涨式轮动/龙头独立行情/边缘题材
- **概念涨幅交叉验证**：东财概念逐日涨幅 TOP20 的上榜持续性（EM 体系）与 THS 轮动矩阵做方向性交叉验证；换手率极低的迷你概念涨幅虚高，不单独作为主线证据
- **情绪周期判定**：基于涨停总数趋势、跌停家数、最高板高度、晋级率、炸板率判断情绪周期位置（冰点/修复/高潮/退潮），作为"大盘适配度"和明日预测置信度的依据
- **主线判定与轮动期战术分组**（2026-08-24 新增）：明确主线 vs 轮动期二选一判定；仅轮动期输出适合追高组/适合低吸组（每组 2-5 个板块，含入选逻辑/操作提示/风险/置信度）；追高看涨停家数走扩+连板高度+资金流入，低吸看趋势未破坏的回调+资金未撤离+蓄势上升；主线明确时不输出分组
- **明日预测**：LLM 推理输出 TOP 3-5 预测板块 + 置信度 + 逻辑链 + 风险提示
- **部分可用降级**：四块数据独立判定可用性（正常输出以 `#` 开头）；全部不可用 → 占位短路；部分可用 → 正常分析但置信度降档（缺梯队/概念涨幅/轮动矩阵/行业基本面 → 上限"中"，缺两块及以上 → 上限"低"）
- **热力图产物**（2026-08-24 新增）：每次分析（非短路路径）生成行业+概念近 10 日逐日涨跌幅热力图（plotly 自包含 HTML，单侧数据不可用只画另一侧），存 `logs/{ts}/reports/charts/sector_daily_heatmaps.html`，logviewer 报告 tab 渲染；失败不阻塞分析

> **数据源**：轮动矩阵使用同花顺（THS）题材板块分类，概念涨幅使用东方财富（EM）概念板块——两套独立分类，与板块新闻/技术分析（EM）不做跨体系名称对齐；连板梯队为全市场混合口径（含 20cm/ST），情绪周期判定优先看主板 10cm 结构。

## 输入

- `trade_date`
- 市场层产出（`cn_tech_report`、`cn_news_report`、`international_news_report`）— 板块层子图入口处组装摘要版上下文

## 产出

- `sector_news_report` — 板块新闻分析完整报告
- `sector_tech_report` — 板块技术分析完整报告
- `sector_shortlist` — 三级别候选板块短名单（结构化字段，下游消费，≤1200 字）
- `sector_tech_confirm` — 候选板块技术确认结论（结构化字段，下游消费，≤800 字）
- `sector_shortlist_structured` — 候选板块名清单 `list[str]`（东财概念体系，供选股层机器消费；2026-08 新增）
- `rotation_prediction_report` — 板块轮动预测完整报告（主线+新热点+退潮+明日预测）
- `rotation_top_picks` — 轮动预测速览结构化文本（供下游展示，≤1200 字）
- `market_regime`（来自市场层）— 三级别市场环境判定
- `market_event_calendar`（来自市场层）— 三级别事件日历
- 文件产物（非 state 字段）：`logs/{ts}/reports/charts/sector_daily_heatmaps.html` — 行业+概念近 10 日逐日涨跌幅热力图（2026-08-24 新增，logviewer 报告 tab 渲染）

## 数据源

共 **12 个**接口函数（12 实现 + 0 占位），位于 `AI/dataflows/` 下。Toolkit 定义在 `AI/stockAgents/utils/agent_utils.py`。

### 双数据源实现（6 个接口方法）

所有板块工具通过 `BaseStockDataProvider` 基类定义接口契约，`AKShareProvider` 和 `TushareProvider` 分别实现。

| 接口方法 | AKShare 实现 | Tushare 实现 |
|----------|-------------|-------------|
| `get_industry_sector_performance(days)` | `stock_board_industry_name_em()` + `stock_board_industry_hist_em()` 遍历；**输出含近10个交易日逐日涨跌幅矩阵（全量不截断，复用已取日线）** | `index_classify(SW2021, L1)` + `sw_daily()` 遍历 31 个申万一级行业；**输出含近10个交易日逐日涨跌幅矩阵（复用已取日线）** |
| `get_concept_board_heat_rank(days)` | `stock_board_concept_name_em()` + `stock_board_concept_hist_em()` 批量获取，热度=涨跌幅×0.6+成交量×0.4；**输出含近10个交易日逐日涨跌幅矩阵（热度 TOP30）** | `dc_index(idx_type="概念板块")` 预筛 TOP30 + `dc_daily()` 计算热度；**逐日章节单元格来自 dc_index 逐日快照（累计列为复利口径），与轮动预测共享 `_DC_CONCEPT_DAILY_CACHE`** |
| `get_sector_technical_screening(days)` | 各行业 `stock_board_industry_hist_em()` 长周期数据 → 计算 MA/RSI/MACD/量比 | 各行业 `sw_daily()` → 计算 MA/RSI/MACD/量比 |
| `get_sector_relative_strength(days)` | 各行业数据 + 上证综指基准 → alpha | `sw_daily()` + `index_daily(000001.SH)` → alpha |
| `get_concept_board(concept_name, days)` | `stock_board_concept_hist_em(symbol=name)` 单个板块 | `ths_index` 名称匹配 → `ths_daily(ts_code)` |
| `get_all_concept_boards(days)` | 遍历 `AI_INDUSTRY_CHAIN` 9 个子板块 | 遍历 `AI_INDUSTRY_CHAIN` 关键词匹配 `ths_index` 名称 |

### 结构化矩阵（2 个，2026-08-24 新增，热力图数据源）

| 接口方法 | AKShare 实现 | Tushare 实现 |
|----------|-------------|-------------|
| `get_industry_daily_returns_matrix(days)` | 复用行业日线拉取（`_fetch_industry_daily_series`） | 复用 `_fetch_industry_daily_series`（sw_daily，升序归一） |
| `get_concept_daily_returns_matrix(days, top_n)` | 复用概念热度批量 hist_em（`_fetch_concept_heat`） | 复用 `_fetch_concept_heat` + `_collect_concept_daily_snapshots`（热度 TOP N 同口径） |

返回结构化 dict `{source, dates, names, pct_matrix}`（dates 升序、缺失格 None）；结构化接口约定：不支持/失败返回 `None`（基类默认）。消费方 `AI/sectorAgents/charts.py` 生成热力图。

> **数据源切换**：通过 `hasattr(prov, 'method')` 自动检测能力，不支持的 provider 继承基类 `_not_supported()` 默认返回，无需硬编码判断。

## 下游消费

> **设计决策（2026-08 更新）**：板块层产出通过**结构化字段**（`sector_shortlist`、`sector_tech_confirm`）注入个股层决策节点。各分析师额外输出紧凑的结构化结论字段（≤800-1200 字），下游通过 `build_cross_layer_context(state)` 完整消费，避免截断丢失关键结论。

> 旧决策（2026-08-02，已废弃）：板块层产出不注入个股层。新方案通过结构化字段实现跨层上下文传递。

### 选股层消费（2026-08 新增）

- News/Tech 分析师结论块新增 `结构化清单: ["板块A", ...]` 行（仅概念板块名），代码提取后经**东财概念全名单**过滤（未命中落选），合并去重写入 `sector_shortlist_structured`
- 仅在 `selectedLayer` 含 `"screening"` 时启用（`SectorLayerGraph(enable_structured_list=...)` 开关），单票模式不产出该字段、不多打名单接口
- 消费端统一**东财概念**体系（Tushare `dc_index`/`dc_member`、AKShare `stock_board_concept_*_em`）；申万行业名/同花顺概念名在过滤中自然落选，板块层自身数据体系与报告不变

### 仅 Tushare 数据（3 个）

AKShare 无对等接口，AKShare-only 环境下由基类 `_not_supported()` 默认返回占位。

| 接口方法 | 实现 | 说明 |
|----------|------|------|
| `get_concept_rotation_ranking(days, top_n)` | `limit_cpt_list(trade_date)` 逐日调用 → 本地规则计算轮动矩阵 + 强度分级 | 打板专题数据；含 `rank` 类型转换、`up_stat` 解析、分位数强度分级、蓄势上升扫描 |
| `get_concept_daily_top_gains(days, top_n)` | `dc_index(trade_date, idx_type="概念板块")` 逐日回退采集 → 按 `pct_change` 降序取 TOP N + 跨日上榜统计 | 东财 EM 概念逐日涨幅矩阵（含换手率，供识别低成交迷你概念）；独立按日缓存（仅非当日日期），与名单/成分股接口的单快照缓存并存 |
