# 运行时目录契约

> 运行时数据与缓存的统一落点约定（2026-10-02 运行时目录收敛方案落库）。所有运行时路径必须遵守本文口径，禁止新增根级运行时目录。

## 一、var/ 单一运行时卷（性质四层）

仓库根只留源码与配置；全部运行时数据在 `var/` 下按性质分组：

```
var/
├── runs/            分析任务产物归档（PlatformArtifactStore 管理：staging→manifest→原子发布、90 天保留、20GB 高水位；docker 卷 liveprofit_artifacts）
├── research/        量化研究数据集（仅容器内 docker 卷 liveprofit_research，主机本地不存在）
├── results/         trading graph 状态日志（var/results/{ticker}/analysis_logs/state_log.json，唯一写入方 trading_graph）
├── logs/            全部日志：run.sh 服务日志+pid、tasks/{task_id}/{attempt_no}/ 执行调用日志、回填/迁移脚本日志、eventStudy 调度日志
├── data/            持久业务数据（不可随意清）：chroma_db/ 记忆库、quant_history/ baostock parquet、backups/ pg 备份审计
├── cache/           可重建缓存：ruff/（[tool.ruff] cache-dir）、pytest/（cache_dir）、pycache/（PYTHONPYCACHEPREFIX）
└── tmp/             临时文件：pytest/（tests/run.py --basetemp，每次运行自动重建）
```

## 二、路径解析契约（与进程 CWD 无关）

| 层 | 机制 | 常量/入口 |
|---|---|---|
| backend | 相对路径常量按 PROJECT_ROOT 解析，单一出口 `resolve_execution_logs_root`（settings.py:151；worker 写/API 读两进程一致，禁止各自解析） | `execution_logs_root = Path("var/logs")`（settings.py:82） |
| AI/db 脚本层 | `_PROJECT_ROOT = Path(__file__).resolve().parents[N]` 推导仓库根后拼绝对路径（N 按文件深度：AI/default_config.py=1、AI/graph/与 AI/utils/=2、AI/eventStudy/scheduler/ 与 db/instrument/ingest|migration/=3） | 各文件模块级常量 |
| 记忆路径 | 单点 resolver `AI.default_config.resolve_memory_path()`：env `LIVEPROFIT_MEMORY_PATH` 绝对值原样用、相对值按 PROJECT_ROOT 解析、未设时默认 `var/data/chroma_db`；全部 chroma 客户端（chromadb_config 4 处 + memory.py 1 处）必须经此 resolver，禁止硬编码 | `.env` 值 `./var/data/chroma_db` |
| 日志读取 | env `LIVEPROFIT_LOGS_DIR` 优先，否则 `parents[2]/var/logs`（logs_reader.py） | — |

## 三、工具缓存契约

- ruff：`[tool.ruff] cache-dir = "var/cache/ruff"`（相对值按 pyproject 所在目录解析）
- pytest：`[tool.pytest.ini_options] cache_dir = "var/cache/pytest"`（按 rootpath 解析）；官方 runner（tests/run.py）用 `-p no:cacheprovider` + `-W ignore::pytest.PytestConfigWarning`（cache_dir 被禁时属未注册配置项）
- 字节码：`run.sh` 顶部 `export PYTHONPYCACHEPREFIX="$SCRIPT_DIR/var/cache/pycache"`（必须在 SCRIPT_DIR 定义之后）

## 四、迁移与清理要点

- 带点文件目录迁移用 `cp -a logs/. var/logs/ && rm -rf logs`（bash `mv logs/*` 不匹配点文件）
- `mkdir -p` 预创建目标目录后再 `mv 源目录 目标/` 会产生嵌套（`目标/源/`）——先 mv 再补目录，或 mv 后检查嵌套
- Windows 坏 ACL 目录（rm/attrib/icacls 全部 Permission denied、连枚举都失败）：`mv` 改名移出仓库（rename 只需父目录权限），再由管理员权限最终删除
