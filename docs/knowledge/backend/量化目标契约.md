# 量化目标日期契约

组合目标的`evaluation_as_of`是可使用的最后行情日，`decision_date`是下达决策的CN日期，`valid_until`为目标失效日期，满足`evaluation_as_of <= decision_date <= valid_until`。FamilyBatchService要求全部成员目标的`evaluation_as_of`等于批次`valuation_date`。

股票/ETF候选及基准行情按`evaluation_as_of`核对，ETF候选的`trade_date`也必须等于该日；ETF月代表选择器可显式传`data_as_of`，省略时沿用同日`decision_date`行为。组合试验入口拒绝任一候选/基准bar或ETF事实晚于`evaluation_as_of`。调仓周/月标志、持仓冷却判断仍依据`decision_date`。例如2026-09-24的已确认行情可以用于2026-09-28决策，9月28日行情不能作为该批次9月24日估值依据。

试验输入尚不证明候选全集完整。`PortfolioTrialResult.disposition`有`TARGET`、`NOT_SCHEDULED`、`NO_TARGET_UNCLASSIFIED`三种取值：`TARGET`必须有intent（其中可以是规则明确生成的`cash_only`）；明确非调仓日返回`NOT_SCHEDULED`；其余无intent返回`NO_TARGET_UNCLASSIFIED`，仍可能是缺证据、筛选无结果或规则无目标。生产入口不可把任何None当作清仓目标。真实目标还要求冻结候选定义与策略版本绑定、资格和完整扫描清单。

`audit_stock_target_universe`只比较同一研究快照instrument上市/退市区间与StockCandidate代码集，并分别报告缺失、额外、重复、不支持代码和证据问题；它不证明上游instrument全集完整，也不授予目标、资格或订单权限。ETF目录及交易规则需独立认证。

四个预注册组合家族可将`PortfolioHoldingPolicy`冻结为`LifecyclePolicyVersion.config.portfolio_trial`（trial_id、definition_hash、holding_policy字段），复用政策版本账本的canonical内容hash。`TargetTrialBindingService.audit_portfolio_policy`只读核验当前策略版本、不可变绑定与该政策版本的完整语义及hash；它不授予目标或资格。真实fill和逐日持仓处理尚未改用此组合政策，生产使用仍受阻。

过渡期旧生命周期服务对组合政策执行拒绝式隔离：风险BUY从活动/订单绑定生命周期、信号与任务快照的版本身份分别检查；任何证据指向`portfolio_trial`均不进入旧模板初始化。每日持仓处理和同日重放也拒绝组合政策。保护SELL仍由成交账本处理；无生命周期绑定的SELL和correct/void后的组合状态对账尚待实现。

组合试验生成明确目标时，`PortfolioTargetIntent`同时携带`trial_id`与`definition_hash`；`PortfolioTrialResult`强制两者与外层结果一致。共同批次对已绑定版本核目标身份、家族、资产范围、政策与冻结政策内容。无绑定版本若目标自称组合政策，或版本指向组合政策，也拒绝投影。旧`EntryBatchService`在新消费时重审成员并拒绝组合目标，避免套用扫描信号的旧模板0.50首仓比例；历史收据重放只返回原收据。经独立认证的组合目标生产、专用目标订单和真实持仓状态仍未实现。

研究历史源读取`market.instrument_daily.amount`原值，单位千元；候选ADV20须在20个可信有效交易日上换算为人民币元。快照`certifiable`仍因独立覆盖、公司行动和证券规则证据缺失而为假，不能从`READY`推导生产目标资格。
研究reader现将`000300.SH`指数原价日线单列为`benchmark_daily`，只读取已知上市日起、退市日前的行；快照按`as_of`截断、核代码/正价/来源，且不混入股票/基金候选。独立交易日连续性和来源可得时点尚未认证，`certification_issues`显式保留该门禁。
股票研究快照若携带`benchmark_daily`，覆盖审计按显式独立交易日历核沪深300每个交易日的有限正收盘，缺日进入独立计数并令快照证据不足；非交易日与错代码拒绝。基金单独快照不冻结也不校验该指数表。日历覆盖通过后，历史来源可得时点仍单独未认证。
`build_stock_candidates`是诊断转换器：按研究快照把股票原价与复权因子逐日合并，以截止日因子归一为前复权收盘；原`amount`千元按最近20个显式交易所开市日换算为人民币元ADV20。仅上市后至少250根有效价、最终日价格/因子/可信状态、完整20日成交额与显式账户held/cooldown事实齐备的证券可形成`StockCandidate`。逐代码缺项进入`gaps`，输出同时带`audit_stock_target_universe`结果；本地候选匹配不证明上游全集、公司行动、账户来源或历史可得时点，不能直接授予生产目标。
`build_benchmark_input`把沪深300快照转换为股票试验所需连续60/120/200个交易日的不可变`(date, Decimal)`序列；缺日、错代码、重复/非交易/未来日期、无效收盘或非股票快照均给诊断且输出空序列。`complete_local`仅表示所需本地窗口完整，`certification_issues`始终包含历史来源可得时点未认证；结果不能直接作为生产目标资格。
`inspect_stock_trial_inputs`按预注册股票试验定义把两个诊断转换汇总：中期动量的冻结`benchmark_ma`决定60/120/200日，短期反转使用120日。结果带trial ID/hash、逐证券与基准诊断、`local_issues`及独立`certification_issues`；本地问题与历史来源/覆盖/账户锁内证明分离。该入口不构造`PortfolioTrialInput`或`PortfolioTargetIntent`，软件输入完整不等于生产资格。
`build_fund_candidates`从基金快照逐证券核目录上市日期、可得时间、上市状态及跟踪指数，与显式类别/停牌事实比对；前复权收盘、原价`atr_bfq`、最近20个交易日金额与复权因子、至少250根上市后日线分别检查。类别`OTHER`单列排除，缺项按证券记gap；分类与停牌来源、ETF交易规则仍未独立认证，不生成月代表或目标。股票转换器也要求最近20日逐日有收盘价和复权因子，避免历史总根数掩盖近期缺行。
`inspect_monthly_fund_representatives`先按快照截止日在市fund全集核候选/显式OTHER/gap分区，再在显式月末按预注册ETF试验调用现有最高ADV选择器。缺基金证据返回`BLOCKED`和`None`代表；非选择日及完整输入无合格代表分别返回不同状态。结果带trial ID/hash、本地与认证问题；历史行情可得时点、独立目录全集及类别/停牌/交易规则仍未认证，既不构造`PortfolioTrialInput`也不生成目标。
`FundRepresentativeRepository.freeze`从`DatasetRepository`重读校验发布快照，并用显式交易日历和分类/停牌事实重算月代表；0024`quant_fund_representative_freezes`保存快照UUID及manifest SHA、预注册trial ID/hash、行情截至日/决策日、完整外部诊断输入、代表和输入hash。联合唯一键保证同一快照/试验/双日期重放；同内容返回原行，冲突拒绝，PG触发器禁止更新/删除。状态固定`DIAGNOSTIC`，仅`SELECTED`或完整输入但无合格代表可保存，不是生产资格、组合目标或建单凭据。

`InstrumentTradingRule`是日期规则消费契约：每条记录含证券身份、类别、执行生效区间、日期级发布日期、来源引用、价格tick、最低/递增/最高买入数量与T+0/T+1。解析器按证券和执行日要求唯一且发布日期早于决策日；同日发布因缺时刻证据保守视为未知。`simulate_opening_buy`已消费此规则及CN日历，要求T为开市日、执行日为下一开市日，用规则tick与数量步长计算1% T日ADV20的含滑点开盘代理。0025已将原文字节与逐证券解释分别持久化，诊断repository读取时核双重hash。`PositionPlanner`可在调用方显式提供逐证券规则时按真实下一开市日、规则tick及最低/递增/最高量裁剪全部BUY预算和ADV20容量；缺键/晚发布/错证券/行情日不等于估值日均拒绝该显式路径。三个真实BUY入口尚未传入认证规则，仍使用旧普通100股/.01 tick路径；来源URI和发布日期仍由调用方声明，未核官方原件，不能作为历史认证或真实订单授权。

`fetch_exchange_rule_artifact`可从交易所HTTPS域当前抓取有界原文字节、请求/最终URI及SHA，`InstrumentRuleRepository.capture_exchange_source`将原文写入0025不可变来源表，并以0026`quant_instrument_rule_captures`追加保存每次请求/最终URI、原文hash、抓取及DB记录时刻。`read_capture_diagnostics`回核采集事件和原文身份。该事件仅证明本进程此次连接取得内容并记录，本地抓取/DB记录时刻都不是历史T日可得证明；`claimed_published_on`仍是请求方声明，逐证券解释及历史可得性均未获认证。诊断来源不得直接作为三个真实BUY入口的授权规则。
显式ETF规则下，共享BUY规划器按冻结风险档采用单ETF证券权重上限20%/25%/30%；同票已有持仓与未完成BUY共占用该额度。股票仍按档位股票上限。`asset_type`当前来自未认证的调用方规则，三个真实BUY入口尚未提供认证规则；此计算行为不构成生产ETF买单授权。
共享BUY规划器收到显式原价入场区间后，先核含滑点建议价仍在区间内，再以不超过上界的最高可成交tick计算RR、风险、仓位、现金含费及T日ADV20容量；建议单`order_cost_price`和预留按该保守价格，`estimated_slippage`只表示基线信号价的预计滑点。历史来源及证券规则认证仍是独立生产门禁。
`materialize_signal_orders`在显式逐证券规则路径会重新核决策日为独立CN开市日、执行日恰为下一开市日以及证券规则日期，并把生命周期首仓比例按规则数量格点向下裁剪。默认调用方尚未提供认证规则，仍保留旧100股路径；调用方自报的`InstrumentTradingRule`不能作为生产授权。
在认证证券规则源接通前，扫描、联合批次和生命周期追加三个真实新BUY入口及信号订单落库均显式给空规则集，新增风险拒绝而不退回普通100股假设。保护SELL维持账本处理。旧活动建议单的当前可执行状态与已发生事实的偏离审计尚待治理。
