## 一、技术栈与构建

- React 19 / Vite 7 / TypeScript 5.8 / Tailwind CSS 4 / @tanstack/react-query v5 / echarts 6.1 / zustand 5
- **pnpm 是唯一包管理器**：`pnpm add` / `pnpm install` / `pnpm run`——`npm install` 会直接报错
- 测试：vitest（`pnpm --dir frontend vitest run <文件>`）；类型/构建：`pnpm --dir frontend typecheck && pnpm --dir frontend build`

## 二、目录结构

```
frontend/src/
├── api/            ← openapi codegen 生成（禁手改，见 §三）
├── app/            ← 应用壳
├── modules/        ← 业务模块（见 §四）
│   ├── analysis/     AI 投研看板（任务/报告/拓扑图）
│   ├── event-study/  事件研究
│   ├── market/       大盘页（指数 K 线 / 热门概念 / 宏观信息）
│   └── watchlist/    自选与组合（queries.ts + watchlists/ + portfolios/）
├── routes/         ← 路由表（routes/index.tsx）
├── shared/         ← 跨模块共享（见 §五）
│   ├── charts/       CandlestickChart（K线/MACD/成交量多 grid）
│   ├── feedback/     EmptyState / ErrorState / LoadingState / NotFoundState
│   ├── format/       dateTime.ts 等格式化工具
│   └── ui/           MarkdownView / ConfirmDialog / 基础控件
└── stores/         ← zustand 全局状态
```

## 三、API client 约定（codegen）

- 前端 API client 由 `openapi-typescript-codegen@0.29.0` 从 `backend/openapi/openapi.v1.json` 生成到 `src/api/generated/`
- **backend 改路由后必须先 `python -m backend.scripts.export_openapi` + `pnpm run generate:api` 再动前端消费代码**（并发编辑下未重导出会让他人 typecheck 失败）
- **不得手写后端领域类型**；[API 契约](../backend/API契约.md) 与 OpenAPI 冲突时以 OpenAPI 为准，发现冲突反馈后端修正
- 坑与细节（codegen tags 分组、Literal 必选/可选两种形态）见 [../../memory/pitfalls/frontend/pnpm-openapi-codegen.md](../../memory/pitfalls/frontend/pnpm-openapi-codegen.md)

## 四、页面与模块

| 模块 | 入口 | 职责 |
|------|------|------|
| market | src/modules/market/pages/ | 大盘页三区块：市场（宏观指数 K 线，`MARKET_INDEX_CATALOG` 12 指数前端写死目录，US→KR→CN 组序）、板块（热门概念 heat_v1）、信息（宏观信息） |
| analysis | src/modules/analysis/pages/ | AI 投研看板：/ai 待处理/进行中/最近结论/新建分析；/ai/tasks 全量任务；/ai/tasks/:taskId 任务详情（SSE 进度 + 报告 + 拓扑图 GraphTopologyPanel） |
| event-study | src/modules/event-study/pages/ | 事件研究：事件提交/审核/影响查看（一次性同步预测，繁忙超时手动重试） |
| watchlist | src/modules/watchlist/ | 自选分组与本地组合（两个独立业务对象；手工持仓不被 AI 建议覆盖） |

## 五、共享组件体系

- **charts**：目前仅 `CandlestickChart`（多 grid：K 线主图 + 成交量 + MACD 副图，H=460 布局；红涨绿跌回调着色；dataZoom 日期锚定 startValue/endValue + datazoom 事件索引→日期上报——**百分比与日期锚互斥，混写时百分比优先、窗口锁死全量**；四线型画线工具（markLine 嵌套两点 + 真实 extent 双向求交，zr 事件交互，localStorage 按标的持久化，drawings.ts 纯函数）；图例 = label+value 三行（行 1 开高低收+量、行 2 MA+BOLL、行 3 DIF/DEA，updateAxisPointer 驱动 + 定向 merge 刷新，ChartCore memo 守卫；开高低收为纯展示项点击无效）；成交量纵轴独立量纲（万/亿手缩写标签）；tooltip `showContent:false`——`show:false` 会连轴失效勿用）
- **拓扑图组件在 modules/analysis**（非 shared）：`components/topologyChartOption.ts`、`pages/task-detail/GraphTopologyPanel.tsx`、`pages/agents/AgentTopologyPage.tsx`
- **ui**：`MarkdownView`（markdown 统一渲染，kind 分流 md/json/txt）、ConfirmDialog、基础控件（button/card/input/dialog/badge/label/checkbox/collapsible）
- **feedback**：空态/错误/加载/404 统一组件

## 六、状态与数据约定

- React Query v5 hooks 按模块收敛于 queries.ts（如 market 的 `useMarketBarsQuery`、watchlist 的 queries.ts）
- placeholderData 渐进加载模式（keepPreviousData 语义）：`useMarketBarsQuery` 已用（指数 K 线按需加载状态机——初始预拉 180 天/可见 90 天，缓冲不变量 loaded ≥ 2×visible + 10% 迟滞，左平移半屏预拉，相邻响应对比到头判定）
- zustand stores 用于全局状态（src/stores/）
