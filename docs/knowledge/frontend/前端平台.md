## 一、技术栈与构建

- React 19 / Vite 7 / TypeScript 5.8 / Tailwind CSS 4 / @tanstack/react-query v5 / echarts 6.1 / zustand 5
- **pnpm 是唯一包管理器**：`pnpm add` / `pnpm install` / `pnpm run`——`npm install` 会直接报错
- 测试：vitest（`pnpm --dir frontend vitest run <文件>`）；类型/构建：`pnpm --dir frontend typecheck && pnpm --dir frontend build`

## 二、目录结构

```
frontend/src/
├── api/            ← openapi codegen 生成（禁手改，见 §三）
├── app/            ← 应用壳
├── modules/        ← 业务模块（见 §四）
│   ├── analysis/     AI 投研看板（任务/报告/拓扑图）
│   ├── event-study/  事件研究
│   ├── market/       大盘页（指数 K 线 / 趋势对比 / 热门概念 / 宏观信息）
│   └── watchlist/    自选与组合（queries.ts + watchlists/ + portfolios/）
├── routes/         ← 路由表（routes/index.tsx）
├── shared/         ← 跨模块共享（见 §五）
│   ├── charts/       CandlestickChart（K线/MACD/成交量多 grid）、LineChart（多序列折线）
│   ├── feedback/     EmptyState / ErrorState / LoadingState / NotFoundState
│   ├── format/       dateTime.ts 等格式化工具
│   └── ui/           MarkdownView / ConfirmDialog / 基础控件
└── stores/         ← zustand 全局状态
```

## 三、API client 约定（codegen）

- 前端 API client 由 `openapi-typescript-codegen@0.29.0` 从 `backend/openapi/openapi.v1.json` 生成到 `src/api/generated/`
- **backend 改路由后必须先 `python -m backend.scripts.export_openapi` + `pnpm run generate:api` 再动前端消费代码**（并发编辑下未重导出会让他人 typecheck 失败）
- **不得手写后端领域类型**；[API 契约](../backend/API契约.md) 与 OpenAPI 冲突时以 OpenAPI 为准，发现冲突反馈后端修正
- 坑与细节（codegen tags 分组、Literal 必选/可选两种形态）见 [../../memory/pitfalls/frontend/pnpm-openapi-codegen.md](../../memory/pitfalls/frontend/pnpm-openapi-codegen.md)

## 五、共享组件体系

- **charts**：`CandlestickChart`（多 grid：K 线主图 + 成交量 + MACD 副图，H=460 布局；红涨绿跌回调着色；dataZoom 日期锚定 startValue/endValue + datazoom 事件索引→日期上报——**百分比与日期锚互斥，混写时百分比优先、窗口锁死全量**；四线型画线工具（SVG 覆盖层渲染 + 真实 extent 求交裁切，zr 仅挂鼠标事件交互——draw/edit 模式均可拖动：线身=整线平移、端点=单锚点，localStorage 按标的持久化，drawings.ts 纯函数）；图例 = label+value 三行（行 1 开高低收+量、行 2 MA+BOLL、行 3 DIF/DEA，updateAxisPointer 驱动 + 定向 merge 刷新，ChartCore memo 守卫；开高低收为纯展示项点击无效）；成交量纵轴独立量纲（万/亿手缩写标签）；tooltip `showContent:false`——`show:false` 会连轴失效勿用）。`LineChart`（2026-09-19 趋势对比面板引入）：多序列折线，x 轴 **type='time'**（类目轴 markLine 小数坐标坑）、数据必须是 `[日期, 值]` 坐标对（time 轴对 `{time,value}` 对象静默不渲染）、y 轴 `scale:true`（归一值域不设 0 起点，差异才可见）、`sampling:'lttb'` 降采样、空序列保留 legend、**不启用 dataZoom**（区间切换在 React 层换查询）；`buildLineOption` 纯函数单测入口；序列色 = dataviz categorical 槽位固定序（暗色 4 槽校验通过）
- **拓扑图组件在 modules/analysis**（非 shared）：`components/topologyChartOption.ts`、`pages/task-detail/GraphTopologyPanel.tsx`、`pages/agents/AgentTopologyPage.tsx`
- **ui**：`MarkdownView`（markdown 统一渲染，kind 分流 md/json/txt）、ConfirmDialog、基础控件（button/card/input/dialog/badge/label/checkbox/collapsible）
- **feedback**：空态/错误/加载/404 统一组件

## 六、状态与数据约定

- React Query v5 hooks 按模块收敛于 queries.ts（如 market 的 `useMarketBarsQuery`、watchlist 的 queries.ts）
- `refreshQueries.ts` 从后端六组状态读取市场本地日期、覆盖版本和自动/手动准入；大盘 scope 只投递指数/板块，量化 scope 只投递个股，任务活跃时仅按本 scope 加快至 10 秒轮询、空闲 5 分钟轮询。大盘仍根据个股版本失效概念树和已展开的活动个股 K 线缓存；历史图表标记过期但不主动加载，页面保留既有图表与历史选择。服务端 Dispatcher 的自动补齐不依赖页面访问。状态接口失败但仍有缓存时，行内提示这是上次核验结果，不用浏览器本地日期推断交易目标。
- 自动市场查询的个股因子策略为 `cache_only`，不会因页面轮询拉上游；用户主动打开或扩大 K 线区间才使用 `ensure`。热门概念最新榜单不传今日日期，显式历史选择才传 `as_of`；指数与趋势范围跟随服务端市场日期更新。
- placeholderData 渐进加载模式（keepPreviousData 语义）：`useMarketBarsQuery` 已用（指数 K 线按需加载状态机——初始预拉 180 天/可见 90 天，缓冲不变量 loaded ≥ 2×visible + 10% 迟滞，左平移半屏预拉，相邻响应对比到头判定）
- zustand stores 用于全局状态（src/stores/）

## 八、视觉与交互基础（2026-09-22）

市场概览的 `MarketRefreshStatus` 以覆盖读模型的 `freshness` 和目标日分子/分母为当前事实。新覆盖已达 `FRESH` 时隐藏旧 PARTIAL/FAILED 任务文案；`HISTORY_GAP` 明示为较早历史时段缺口，不能理解为当前目标日未更新。`CATALOG_INCOMPLETE` 仅指股票主目录内标的缺上市生命周期，不把 DC 板块成分中尚未入目录的 IPO 代码作为个股日线分母。

行情拉取状态以简短可换行的提示置于指数、板块及量化扫描各自区块；大盘页首无独立进度面板。指数摘要卡将名称/代码及价格/涨跌幅分别同行，日期/币种/闭市信息同属次要元数据；展开的 K 线若仍锚定最新交易日，市场日期变化时随新日线平移可见窗口，用户手动平移到历史日期时保持原窗口。

- CSS token 提供「钛灰冰蓝」深色（背景 #161A20 / 面板 #232A34 / 主色 #91BFF4）与「象牙钴蓝」浅色（背景 #F1EFEA / 面板 #FFFEFB / 主色 #5267C7）两套主题；根节点 dark/light 互斥，首屏读取持久化偏好，浏览器 theme-color 同步切换。主色填充使用独立 color-accent-foreground 保证文字对比度（深色为深字、浅色为白字）。面板光晕、阴影、入场/悬浮动效遵守 prefers-reduced-motion。
- 应用壳按视口选择展开侧栏、紧凑侧栏或移动抽屉；中等宽度的临时紧凑不改写持久化偏好。菜单 Esc 关闭并恢复焦点，有跳至主内容入口。
- useChartTheme 统一轴线/网格/文字。K 线主题通过 merge-only setOption 刷新颜色，不能重建完整 option 或附带 dataZoom。
- 拓扑节点间距 180px、层间距 120px；零跨度轴使用 2px 范围校正。行标签用真实 dataToPoint 对齐。长标签最多两行，完整节点名放可访问列表；宽图只在画布容器内滚动。
- PercentField 对外显示百分数，提交除以 100 一次；未改值保留原始浮点精度。设置与持仓保存使用编辑开始的版本快照，父列表不得用版本 key 或后台错误早返回卸载草稿。
- MarkdownView 默认允许图片；事件原文显式 imagePolicy=text，只显示替代文字，禁止加载远程图片。HTML 清理仅去已知排版标签并单次解实体，其余经统一 Markdown 安全渲染。
- API 错误先给行动提示，原始 code/message 折叠展示；缓存更新失败与旧数据并存，空缓存数组也须保留失败与重试反馈。
