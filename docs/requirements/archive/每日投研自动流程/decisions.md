# 关键决策记录

## 2026-09-23 用户需求与设计默认值

- 背景：用户希望新闻周期分析和每日收盘量化自动串联，复用现有 agent。
- 明确需求：双 agent 判新/打标，最多两轮辩论；下一交易日市场判断；多策略股票及历史事件权重。
- 2026-09-23 用户追加并确认：按 news + event_assessment 的设计继续；每天自动获取/打标事件，分别分析未来一周和一个月偏利好或利空，跟踪利好/利空消息公布与实施后实际市场反应。现有代码只有独立事件服务可配置的08:30批处理、人工审核预填、事件后5日历史窗口，尚未提供该闭环。
- 设计口径：日报列出下一交易日/未来5/20个交易日及实际日期；“落地”拆为有公告证据的事实阶段和有行情支持的市场兑现，原判断与到期验证分开保存；一周/一月按5/20个交易日为可配置默认，若用户明确自然日口径再调整。
- 2026-09-23 用户明确新闻运行时点：每天 Asia/Shanghai 09:00 前应完成盘前新闻分析，每天21:00应有晚间事件分析，页面需手动新闻分析按钮。09:00/21:00 为每日独立新闻/市场批次。
- 整点边界：持续采集并在整点前加密抓取/研判；news_cutoff_at 为09:00或21:00，报告保留 first_seen_at 与 report_as_of。整点前最后一秒到达的新闻无法保证整点完成 AI；先发布含 coverage/backlog 的 partial，完成后产生真实时间的新版本，绝不倒填或声称“所有新闻均已完成”。
- 2026-09-23 用户补充量化时间与手动入口：每天21:00**开始运行**全部启用量化策略，页面可单独手动启动；与21:00新闻/市场整点版并行。原拟15:30自动扫描改为15:30仅可预检/补齐行情，21:00才准入策略。页面区分“立即分析新闻”和“运行全部量化策略”，不把一个按钮暗中触发另一条链。休市无新收盘日自动复用上一完整量化结果并标明日期；手动可选最近完整交易日显式重跑。
- 2026-09-23 用户补充事件研究 UI：每天新闻已经由系统采集，事件研究不应再要求自己填事件文本。每次09:00/21:00或人工新闻分析均根据当版新获知/更新及仍有效的既有事件预测，结果按批次持久化；页面默认事件列表/预测详情，`event_id` 跳转定位记录；人工操作集中于触发分析、争议和更正。旧同步自由文本预测 API 暂保留调用方兼容，但退出日常页面主路径。
- 设计建议：持续新闻队列 + 每日持久化编排；全部启用策略各一个发布版本；先扫描后统一规划；市场/板块一次、个股只研究重点候选与持仓。
- 理由：现有 AI 在量化后执行、只合并报告；多策略分别生成仓位会重复分配预算。
- 默认参数尚未拍板：30分钟、90自然日、前10深研、±20事件分、半衰期和0.8自动通过阈值都需可配置与验收。
- “权重”一期明确为候选排序分及事件加减分，不输出建议仓位或订单。
- 用户最新原则：目标是最佳整体设计，不是“非必要不建表”。已写入根 AGENTS.md；比较业务语义、生命周期、约束查询、一致性、性能及维护成本后给出明确推荐。
- 命名与去重：按用户建议将拟建原文表命名为 news，关联字段为 news_id；一行仍代表来源内容版本。程序去重复抓取，Agent A 判事实重复/新进展，程序与数据库校验提交并防并发重复；跨来源原文不因语义归并而删除。
- 当前存储推荐：新增 news 与 event_assessment 两张业务表，分别保存来源原文版本与正式判断版本；复用现有任务/报告/受保护产物保存执行过程。零新表可以实现，但不作为本需求的推荐方案。
- 修正原方案：assessment 不再以 record_kind 混放 control/response/final/embedding；标签正文不可变，固定模型向量仅允许一次派生填充并记录独立可用时间。需要多模型向量历史时再建立相应模型。
- 首期同一物理 PG 库、共享事务连接提交任务完成和业务结果；启动前核验实际拓扑，不自动切换连接或迁库。减少无业务要求的跨库协调成本。
- 复用 quant 信号及订单；调度配置文件化，可重建缓存使用 Redis；不因减少表数把业务身份和版本约束移入缓存。
# 实施期范围澄清（2026-09-23）

- 每晚量化一期以用户明确的目标为准：全策略扫描、筛选候选股票，并按近几个月已结构化利好/利空事实计算事件权重、展示排名。
- 一期不生成组合仓位或建议订单，也不按所有组合重复扫描。组合级持仓审查、冲突候选复核和仓位规划属于后续独立能力；需要明确组合绑定与策略所需持仓上下文后再设计。本次实现不把它作为 T5 验收阻塞项。
- 对没有可审计期限标签的存量 `events`，不从当前可变投影或历史价格反推“当时已知”的标签；日报披露未结构化数量，并将事件证据完整性设为 false。
