# 回顾

原件快照与迁移映射使业务失败能够同布局新增问题分开核对，保留原测试身份及断言比单看通过数量可靠。共享 helper 抽取必须保全函数全局变量与 monkeypatch 作用对象，收集通过不能证明这些运行语义正确；独立复核发现并关闭了相关问题。

真实依赖限制与 unit/integration 分层分别维护；混合文件按 fixture 拆分，默认门禁再覆盖动态请求。父进程模块赋值不能传入 CLI 子进程，显式环境与隔离库名校验已补齐。首次实际使用模块入口还暴露临时父目录缺失，定向回归已固定该行为。

没有因存量量化、提示词、调度器或行情参数失败扩展到无关业务修补。后续新增模块维护 suites 索引，实际验收按调用链和关键风险确定关联范围；提交前先整理已有未提交业务边界。
