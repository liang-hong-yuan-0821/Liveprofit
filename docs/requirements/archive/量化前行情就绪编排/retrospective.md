# 复盘

- 量化输入不是“行情日线已完成”的同义词。预检必须按策略真实读取的日线、qfq、复权因子和交易状态分别核验，且采集覆盖与量化执行股票池共用一个事实查询。
- 对截止型 readiness 错误，pipeline 抛出可重试异常还不够；task lifecycle 的错误码白名单也决定任务能否等到 deadline。新错误码需要 pipeline、生命周期白名单和 lifecycle 测试一起落地。
- Redis coverage 按资源缓存时，要额外审视资源间共用的事实表。资源 A 写入被资源 B 读取的表时，双方的 coverage 缓存都应失效。
- 16:00 手动分析是否使用最近完整行情，不能只看提交时间规则；刷新准入可能把目标交易日解析成前一交易日，报告应以实际预检日期校正标志。
- 方案文件清单与验证承诺应在收尾时和实际 diff、测试名逐项对照，避免实现已扩展而任务追踪文档仍停留在最初边界。

本次真实 LLM 测试按仓库规则不自动运行。由于共享工作区中还有多条并行功能的未提交改动，任务归档完成但没有创建 commit，避免将来源不明的修改一并提交。
