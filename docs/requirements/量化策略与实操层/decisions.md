## 2026-09-17 脚本入口保持「用户自己输入代码」

- **背景**：模板库方案（待确认）提出「V1 不开放自定义源码编辑，前端只选模板+参数、服务端渲染源码」；本任务已实现 CodeMirror 编辑器 + ruff 格式化 + 新建必填代码。
- **选项**：a) 按模板库方案改参数表单、移除源码编辑；b) 保留自定义源码编辑，模板库方案该条按过期处理；c) 两轨并存。
- **结论**：**b**——用户拍板「模板库方案比较老旧，需要自己输入代码」。
- **理由**：模板库方案基于旧冻结稿且未确认；模板能力将来以「模板选择器把渲染源码填入编辑器」补充即可，源码编辑始终是入口。

## 2026-09-17 行业覆盖率口径：活跃股票口径（M7 方案 A）

- **背景**：CR 指出覆盖率=成功行业数/31 无法检出「非空但被截断」的行业帧（31 行业全成功即放行，实际归属覆盖率可能极低）。
- **选项**：a) 有行业归属的活跃股票数/活跃股票总数 ≥0.95；b) 维持成功行业数/31。
- **结论**：**a**——用户拍板，新增失败码 `INDUSTRY_COVERAGE_LOW`。
- **理由**：防截断漏放；plan 4.3.1 与采集模块已同步改写。
