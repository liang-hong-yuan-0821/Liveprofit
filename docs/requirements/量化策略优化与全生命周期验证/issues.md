## 当前统一问题台账（2026-09-26，主线优先）

用户决策：先推进策略主线；已知问题统一记录、按根因集中分析与治理，不再逐条追数据或遇到一个症状就展开一轮补丁。下表是当前状态入口；后文时间线保留历史证据，其中旧缺口数字不代表当前现状。

### 分流与关闭规则

- **立即处理**：确实阻塞当前主线可执行验收，或会破坏数据、账户、交易约束一致性的问题；先写明阻塞证据及最小处理范围。
- **集中治理**：可隔离的数据、来源、历史证据问题，登记后继续主线；研究认证和新增风险门禁保持关闭条件，不以延期治理冒充数据已齐。
- **主线顺序**：T2策略契约和76候选 → T3统一规划与风险 → T4账本与生命周期 → T5研究内核/准入 → T6账户流水线 → T7界面 → T8整体验证。允许依赖接口和固定夹具先行，真实数据认证单独设门禁。
- **系统治理顺序**：G1来源能力与身份 → G2状态/规则/公司行为模型与历史可得性 → G3覆盖与暖机统一口径 → G4采集、重试、调度和观测 → G5全范围回归。每组先枚举所有生产者、持久表、消费者和失败路径，再统一修复同类问题。
- **状态**：待系统分析 → 已定位待治理 → 治理中 → 待验收 → 已关闭。原因不清楚必须写“待查”，不能把推测当根因。
- **每项必填**：可复現现象、受影响范围、已证实原因/未知部分、临时隔离、所属治理组、主线门禁、验收证据。新发现先归入同类ID，独立根因才新增ID。
- **关闭标准**：同类影响面枚举完整、正常/边界/失败反例通过、真实范围核验或明确能力边界、消费者口径一致、任务与证据同步。一次请求成功、一个样本正常或补采行数增加均不能单独关闭问题。

## 2026-09-26 2017年暂停上市误判与因子暖机边界

- **表象**：因子回填后2017年仍报55,623个缺日线证券日、26,826个组合因子缺口；完整状态缺796,033。仅靠日线缺行推断停牌不安全，按交易所交易日数判断暖机又会把长期停牌股票误判为逾期缺因子。
- **解决**：独立逐日`suspend_d`批次244日全成功、核验54,383条全天停牌；余1,442条仅分布于000155、000629、000950、600806、600432、600710、300372、000511、600732、000033共10只暂停上市证券。逐只核查[公告清单](attachments/suspension_evidence_2017_listing_pauses.json)的暂停/恢复/退市整理区间后入库，年度未解释缺日线变0。上交所原始上市公告HTML纳入严格公告URL白名单，仅限`www.sse.com.cn/disclosure/announcement/listing/*.shtml`、HTTPS、无查询参数；2018-05-22上交所公告追溯确认600806自2017-05-23暂停上市。
- **因子边界**：[逐票暖机验证](attachments/factor_warmup_2017_verification.json)按真实日线根数计算，539只股票的26,826条缺口最高第59根，整行与ATR缺失不越第20根，首根日线均为上市日；上市至缺口日期间所有交易所开市而无日线的证券日均有可信全天停牌证据。可将这些**因子**余项归为窗口暖机，不代表ST状态完整。
- **剩余**：2017年完整状态仍缺7,769条，均无`trade_status_daily`行；其中有日线5,881条、无日线1,888条。1月17日与6月23日`stock_st`源空导致整日缺行，其余多为暂停上市长期空窗。公告仅证明停牌，不提供完整ST/板块字段；在历史状态源补证前保持未知并阻断要求该状态的as-of研究。
