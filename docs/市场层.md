# 市场层 — 宏观市场分析独立子图

> **架构定位**：三层 Subgraph 金字塔的第一层。先于板块层和个股层执行，不依赖 ticker。
>
> **关联文档**：[index.md](index.md) | [板块层](板块层.md) | [个股层](个股层.md)
>
> **实现状态**：✅ 已实现 → [施工方案](plans/市场层重构方案.md)

---

## 架构

市场层是一个**独立编译的 LangGraph 子图**（`AI/marketAgents/market_layer_graph.py`），与父图共享 `AgentState`，写入市场层字段后由个股层读取。

```
顶层 Graph
├── Subgraph: 市场层（独立编译）  ← 本期已实现
│   ├── Layer 0: 国际新闻分析 (Global)
│   └── Layer 1: 各国市场分析 (US / KR / CN)
├── Subgraph: 板块层（预留占位）
└── 个股层 + 辩论 + 风控
```

## Layer 0 — 国际新闻分析

**合并原设计的"宏观事件驱动层 + 历史案例分析"**，在一个 Agent 内完成。

- 地缘政治冲突、战乱、重大自然灾害
- 全球流动性/利率政策（Fed / PBoC / ECB）
- 宏观经济数据（CPI / 非农 / PMI / 社融）
- 大宗商品/汇率联动（原油 / 黄金 / 美元指数）
- 逐事件检索历史案例，给出相似度 + 传导链条 + 资金虹吸提示
- 系统性风险评估（低/中/高）

## Layer 1 — 中国市场 (CN) ★

主战场，分析最深：

**新闻分析**：资金日历事件
- 大盘 IPO / 新股上市（打新抽血效应）
- 限售股解禁（潜在抛压）
- 期货/期权交割日（到期日效应 → 尾盘波动放大）
- 融资融券余额（杠杆资金松紧）
- 季节/事件效应（季末调仓、长假避险）

**技术分析**：大盘环境温度计
- 7 指数量价（上证/深证/创业板/科创50/上证50/中证1000/上证红利）
- 市场宽度（涨跌比、涨停跌停统计）
- 资金流向（北向/主力，标注 2024-08-16 后北向仅日终汇总）
- 风格因子（上证50 vs 中证1000 = 大小盘；创业板 vs 上证红利 = 成长vs价值）

## Layer 1 — 美国/韩国市场

分析深度较中国轻，每国 = 新闻 + 技术两个 Agent：

| 市场 | 新闻分析 | 技术分析 |
|------|----------|----------|
| 美国 | 美联储政策、经济数据（CPI/非农）、VIX、财报季 | 标普500/纳指/道指趋势+均线+RSI |
| 韩国 | 央行政策、出口数据、权重股动态 | KOSPI/KOSDAQ + 与美股科技相关性 |

## 下游消费

市场层 7 份报告通过 `build_market_layer_context()` 组装，注入到个股层的 9 个下游节点（bull/bear researcher、research_manager、trader、risk_manager、3 debators、reflection）。

## 数据源

共 **19 个**接口函数（14 实现 + 5 占位），全部位于 `AI/dataflows/interface.py`。

### Global — 国际宏观（5 个，全部实现）

| 函数 | 实现方式 |
|------|----------|
| `get_global_macro_news(curr_date)` | AKShare `stock_telegraph_cls()` 财联社电报，固定获取近期窗口 |
| `get_central_bank_calendar(curr_date)` | 静态 JSON（`central_bank_calendar.json`）+ AKShare `macro_*` 补充最新利率 |
| `get_macro_indicators(curr_date)` | AKShare `macro_usa_cpi()` / `macro_usa_non_farm()` / `macro_china_pmi()` / `macro_china_shrzgm()` 等，逐端点 try/except |
| `get_commodity_fx_overview(days=10)` | AKShare 期货（WTI/Brent）+ 现货（黄金）+ investing 指数（美元） |
| `get_event_calendar_history(events_desc)` | 静态 JSON（`historical_cases.json`）关键词匹配，不依赖外部 API |

### US — 美国市场（5 个，3 实现 + 2 占位）

| 函数 | 状态 | 实现方式 / 降级策略 |
|------|:---:|------|
| `get_us_economic_calendar(curr_date)` | ✅ | AKShare `news_economic_baidu()`，按地区过滤 US 条目（CPI/非农/GDP 等，含公布值/预期/前值） |

### CN — 中国市场（6 个，全部实现）★

| 函数 | 实现方式 |
|------|----------|
| `get_ipo_calendar(curr_date)` | AKShare `stock_ipo_em()`（申购）+ `stock_new_a_spot_em()`（上市），合并去重 + 大市值标注 |
| `get_share_unlock_calendar(curr_date)` | AKShare `stock_restricted_release_queue_em()`，按日期过滤近期解禁 |
| `get_futures_expiry_calendar(curr_date)` | 规则计算（每月第三个周五）+ `ak.tool_trade_date_hist_sina()` 交易日历校验 |
| `get_margin_trading_balance(curr_date)` | AKShare `stock_margin_sse()` + `stock_margin_detail_szse()`，合并沪深两所数据 |
| `get_market_breadth(curr_date)` | AKShare `stock_market_activity_legu()`，单端点含上涨/下跌/涨停/跌停家数 |
| `get_market_fund_flow(curr_date)` | AKShare `stock_hsgt_fund_flow_summary_em()`（北向）+ `stock_fund_flow_big_deal()`（主力）；北向 2024-08-16 起仅日终汇总 |

### 占位函数的降级策略

5 个占位函数统一返回 `"数据不可用"`，Agent prompt 已明确要求"数据不可用时如实标注，靠 LLM 训练知识做方向性判断"。美/韩 Agent 体量轻（每个 prompt ≤ 50 行，工具 ≤ 3 个），不完全依赖实时数据。

> **Tushare 降级**：中国市场新增工具在 Tushare 模式下返回"数据不可用（当前数据源不支持，请切换到 akshare）"。`get_china_market_overview` 扩展在 Tushare 下可正常工作（Tushare 支持 7 个指数的日线）。

> 旧设计（`MacroMarketAnalyst → HistoricalCaseAnalyst` 两阶段串行）已废弃——合并为国际新闻分析的单一 Agent 内完成。
