## 架构

板块层是一个**独立编译的 LangGraph 子图**（`AI/sectorAgents/sector_layer_graph.py`），与父图共享 `AgentState`，写入板块层字段后保持独立（不注入个股层决策节点）。

```
顶层 Graph
├── Subgraph: 市场层（独立编译 ✅）
├── Subgraph: 板块层（独立编译）    ← 本期实现
│   ├── 板块新闻分析 (Sector News)  — 行业排名 + 资金流向 + 板块轮动
│   └── 板块技术分析 (Sector Tech)  — 全行业技术扫描 + AI专题深挖 + 风格验证
└── 个股层 + 辩论 + 风控
```

## 板块层内部结构

| Agent | 文件 | 输出字段 | 工具循环 |
|-------|------|----------|:---:|

## 板块新闻分析

**职责**：从"信息面 + 资金面"维度，扫描全市场行业板块和概念板块的状态。

- 申万一级/二级行业近 N 日涨跌幅排名，识别领涨/领跌行业
- 行业板块主力资金净流入/流出排名，判断资金进攻方向
- 热门概念板块的涨幅、成交额变化、持续性判断
- 近期产业政策/事件对相关板块的催化
- 板块轮动主线判断（有主线/快速轮动/无方向）及置信度

## 板块技术分析

**职责**：逐行业做技术面体检，输出全行业技术状态全景图。覆盖 A 股所有申万一级行业（汽车、医药、食品饮料、电力设备、电子、银行……）。

- **全行业技术扫描**：逐行业做均线/趋势/量价分析，输出技术状态矩阵（强势/中性/弱势）
- **行业相对强度 (alpha)**：各行业相对大盘的超额收益排名
- **板块轮动技术验证**：对新闻分析识别的"主线"做技术面确认（趋势健康度、量价配合）
- **行业技术风险扫描**：领涨行业是否出现背离/高位放量滞涨；超跌行业是否出现底部企稳信号
- **AI/科技产业链专题**：科技相关行业的上下游轮动分析（存储芯片→半导体→光模块→AI服务器→算力→AI应用）
- **全球科技映射**：美股科技→韩股科技→A股科技板块的传导有效性判断

## 数据源

共 **8 个**接口函数（5 实现 + 1 占位 + 2 已有复用），位于 `AI/dataflows/interface.py` 和 `AI/agents/utils/agent_utils.py`。

### 新增实现（5 个）

| 函数 | 实现方式 |
|------|----------|
| `get_industry_sector_performance(days=10)` | AKShare `stock_board_industry_name_em()` + `stock_board_industry_hist_em()` 遍历，计算近 N 日涨跌幅排序 |
| `get_sector_fund_flow(days=5)` | AKShare `stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流向")`，单端点直接满足 |
| `get_concept_board_heat(days=10)` | AKShare `stock_board_concept_name_em()` + `stock_board_concept_hist_em()` 批量获取，按涨跌幅+成交额综合排序 |
| `get_sector_technical_screening(days=60)` | 复用行业数据长周期版本，逐行业计算均线排列/RSI/MACD/量比，输出技术状态矩阵 |
| `get_sector_relative_strength(days=20)` | 复用行业数据 + 上证综指基准，计算各行业 alpha 排名 |

### 已有工具继承（2 个）

| 函数 | 说明 |
|------|------|
| `get_ai_industry_chain(days=10)` | AI 产业链各细分板块数据，从旧 `tech_market_analyst` 继承 |
| `get_tech_correlation_analysis(days=10)` | 全球科技指数相关性 + 趋势预测，从旧 `tech_market_analyst` 继承 |

### 占位（1 个）

| 函数 | 降级策略 |
|------|----------|
| `get_industry_policy_news(curr_date)` | 占位：无免费行业政策聚合接口，Agent 靠 LLM 知识推断 |

> **Tushare 降级**：所有板块工具在 Tushare 模式下返回"数据不可用（当前数据源不支持板块数据，请切换到 akshare）"。
